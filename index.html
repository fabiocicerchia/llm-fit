📏 llm-fit

Which LLMs this machine can actually run, and how fast.

Reads the hardware, does the memory and bandwidth arithmetic, and recommends a model, a quantization and a runtime — with an estimate of the tokens per second you will get. Seven runtimes with their real constraints, GQA/MLA/MoE handled as distinct cases, measured host memory bandwidth. No dependencies outside the standard library.

Install
go install github.com/fabiocicerchia/llm-fit/cmd/llm-fit@latest

or, from a checkout: make build # ./bin/llm-fit

Use
llm-fit detect                    # what is here, and what it implies
llm-fit suggest                   # models that run well, best first
llm-fit check qwen3-30b           # every quant × runtime for one model
llm-fit check -hf Qwen/Qwen3-14B  # any model, read from Hugging Face
llm-fit suggest -gpu "RTX 4090"   # plan for hardware you do not have yet

estimates from bandwidth and compute, not measurements — usually within about 20%
